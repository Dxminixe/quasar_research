The Codes Created for Dr. Bird's Quasars in the Lyman-Alpha Forest research. 

QSO & COADD Crossmatch 
  This code was used to help catalog possible quasars within the DESI's coda and qso files. These files can be found through their website, under the first year publications. The goal was to utilize the code to match any stellar objects in the coadd file with the objects in the qso file, specifically for objects having a redshift ('Z') of 2.1 or higher.
